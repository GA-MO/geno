แต่ละคอลัมน์คือหนึ่ง lane เรียงตาม process จากคนไปจนถึงระบบภายนอก แถบด้านหลังรวม lane ที่อยู่ใน process เดียวกัน
ตัวเลขบนกล่องคือจำนวนสถานการณ์ที่ผ่านส่วนนั้น กล่องเส้นประคือส่วนที่ยังไม่มีสถานการณ์ผ่าน
เส้นเชื่อมไม่ได้วาดด้วยมือ มันมาจากทุกครั้งที่สถานการณ์หนึ่งเดินจากส่วนหนึ่งไปอีกส่วน ตอนแรกแสดงเฉพาะทางหลัก
คลิกส่วนใดก็ได้เพื่อดูทุกเส้นเข้าออกของมัน เส้นยิ่งหนายิ่งมีสถานการณ์ใช้มาก
