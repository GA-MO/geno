แผนที่นี้แบ่ง Geno ละเอียดกว่าผู้เล่นห้าฝ่ายของทัวร์ แต่ละคอลัมน์คือส่วนหนึ่งของระบบ เช่น แผงแชต ลูปเอเจนต์ นโยบาย (ส่วนที่ตัดสินสิทธิ์) หรือ tool
คอลัมน์เรียงจากคนไปจนถึงระบบภายนอก แถบด้านหลังรวมคอลัมน์ที่รันใน process เดียวกัน
ถ้ายังไม่รู้ว่าแต่ละ process คืออะไร อ่าน[ส่วนประกอบของ Geno](/foundations/parts-of-geno/) ก่อน
ตัวเลขบนกล่องคือจำนวนสถานการณ์ที่ผ่านส่วนนั้น กล่องเส้นประคือส่วนที่ยังไม่มีสถานการณ์ผ่าน
เส้นเชื่อมไม่ได้วาดด้วยมือ มันมาจากทุกครั้งที่สถานการณ์หนึ่งเดินจากส่วนหนึ่งไปอีกส่วน ตอนแรกแสดงเฉพาะทางหลัก
คลิกส่วนใดก็ได้เพื่อดูทุกเส้นเข้าออกของมัน เส้นยิ่งหนายิ่งมีสถานการณ์ใช้มาก
