## Geno คืออะไร

Geno เป็นเอเจนต์เขียนโค้ดใน VS Code ที่มีลูปของตัวเอง
ลูปนั้นไม่ได้รันใน extension host แต่รันใน **engine daemon** แยกต่างหาก (`gcode serve --socket`)
extension host เป็น client ของ ACP ที่คุยกับ engine ผ่าน Unix socket ส่วนแผงแชตเป็น webview ที่คุยกับ extension host เท่านั้น

prompt หนึ่งข้อของผู้ใช้กลายเป็นคำขอ ACP `session/prompt` หนึ่งคำขอ และคำขอนั้นค้างอยู่จนกว่า turn จะจบ
ระหว่างนั้น engine ผลัดกันทำงานกับโมเดล:
โมเดลตอบหรือขอเรียกเครื่องมือ harness ตรวจสิทธิ์ รันเครื่องมือ แล้วส่งผลกลับไปให้โมเดล
วนอย่างนี้จนโมเดลจบ turn หรือมีอะไรมาหยุด

คำว่า **harness** ในเว็บนี้หมายถึงทุกอย่างที่ไม่ใช่โมเดลและไม่ใช่ผู้ใช้:
แผงแชต extension host เซิร์ฟเวอร์ของ engine ลูป เครื่องมือ และนโยบายสิทธิ์

## เว็บนี้อ่านอย่างไร

- **[สถานการณ์](/scenarios/)** คือหัวใจของเว็บ แต่ละหน้าเป็นทัวร์ที่เดินได้ทีละขั้น
  เห็นว่าใครกำลังทำ เรียกโมเดลไปกี่ครั้ง รันเครื่องมือไปกี่ครั้ง และ turn จบแบบไหน
  ทุกขั้นมีลิงก์ไปยังบรรทัดในโค้ดที่ทำงานจริง
- **[แผนที่ระบบ](/map/)** แสดงทุกส่วนของระบบตาม process คลิกส่วนใดก็ได้เพื่อกระโดดเข้าทัวร์ที่ผ่านส่วนนั้น
- **แนวคิดหลัก** อธิบายภาพรวมด้วยแผนภาพ เช่น [process ของระบบ](/concepts/processes/)
  และ [เครื่องสถานะของ turn](/concepts/turn-state-machine/)

ก่อนเดินทัวร์แรก อ่าน [วิธีอ่านทัวร์](/start/how-to-read/) สักสองนาที

## เริ่มจากตรงนี้

1. [ถามแล้วได้คำตอบเป็นข้อความ](/scenarios/turn/text-answer/) เส้นทางที่สั้นที่สุด ทุกสถานการณ์อื่นแตกออกจากเส้นนี้
2. [โมเดลเรียกเครื่องมือแล้วตอบ](/scenarios/turn/with-tools/) วงรอบ เรียกโมเดล รันเครื่องมือ เรียกโมเดลอีกครั้ง
3. [โหมด Ask ขออนุญาตก่อนรันคำสั่ง](/scenarios/perm/ask-mode-bash-approval/) ทางแยกสี่ทาง และทางที่จบ turn ทันที
