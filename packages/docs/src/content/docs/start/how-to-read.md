ทุกหน้าสถานการณ์เล่าเรื่องหนึ่งเรื่อง ตั้งแต่สิ่งที่เริ่มมันจนถึงตอนจบ
เรื่องแบ่งเป็น **beat** ราว 8 ถึง 15 จังหวะ แต่ละจังหวะคือช่วงที่ฝ่ายหนึ่งทำอะไรบางอย่างแล้วส่งต่อให้อีกฝ่าย

เอกสารใช้คำของ agent harness เช่น turn tool และ permission ทุกคำมีคำอธิบายสั้นใน[คำศัพท์](/start/glossary/)
ถ้าอ่านเป็นครั้งแรก เริ่มจากบท "พื้นฐาน" ซึ่งสอนคำเหล่านี้ตามลำดับ

## ผู้เล่นห้าฝ่าย

ทุกทัวร์ใช้ผู้เล่นชุดเดียวกัน

| ผู้เล่น | คือ |
| --- | --- |
| **คุณ** | คนที่พิมพ์ คลิก ตอบการ์ด และกด Stop |
| **Geno panel** | แผงแชตใน VS Code และส่วนของ Geno ที่รันใน VS Code |
| **Geno engine** | โปรแกรมเบื้องหลังที่เดิน turn (ช่วงตั้งแต่คุณส่ง prompt จนคำตอบจบ) มันวนเรียก model ตรวจสิทธิ์ และส่งข้อมูลไปมา |
| **AI model** | model ภาษาที่ตอบคุณหรือขอใช้ tool รวมถึง subagent (บทสนทนาลูกที่ model สร้างให้ทำงานย่อยแล้วรายงานกลับ) |
| **เครื่องของคุณ** | shell ไฟล์ และระบบนอก Geno ที่ tool ไปแตะ |

ป้ายสีบนแต่ละจังหวะบอกว่าใครเป็นคนทำ: **คุณ** (ส้ม) **AI** (ม่วง) และ **Geno** (เขียว)
ป้ายมีแค่สามสี Geno panel Geno engine และเครื่องของคุณ (งานที่ tool ทำ) ใช้ป้าย **Geno** สีเขียวเหมือนกัน

## สองมุมมองของเรื่องเดียวกัน

- **Sequence** (ค่าเริ่มต้น) ผู้เล่นเรียงเป็นคอลัมน์ แต่ละจังหวะเป็นลูกศรจากผู้เล่นหนึ่งไปอีกคน อ่านจากบนลงล่าง
- **Swim lane** ผู้เล่นเรียงเป็นแถว แต่ละจังหวะเป็นกล่องในแถวของคนที่ทำ อ่านจากซ้ายไปขวา

กดสลับได้ที่ปุ่มเหนือแผนภาพ เว็บจำมุมมองที่คุณเลือกไว้

## ทางแยก

เมื่อเรื่องขึ้นกับการตัดสินใจ เช่นคุณกดปุ่มไหนบนการ์ดขออนุญาต แผนภาพแสดงเป็น **ข้าวหลามตัด**
ทางที่เลือกอยู่เดินต่อในแผนภาพ ทางอื่นแสดงเป็นกล่องเส้นประพร้อมบอกว่าทางนั้นไปจบที่ไหน
คลิกทางไหนก็ได้เพื่อเดินทางนั้นแทน ตัวเลข "จังหวะที่ 3 จาก 9" นับตามทางที่เลือกอยู่

## การ์ดอ่าน

การ์ดข้างแผนภาพเล่าจังหวะปัจจุบัน

- ชื่อจังหวะ ใครทำ และส่งจากใครถึงใคร
- เรื่องเป็นภาษาไทยสองสามประโยค
- **สิ่งที่คุณเห็น** หน้าตาจริงของสิ่งที่ขึ้นบนจอคุณ เช่นการ์ดขอ permission หรือแถวในแชต ข้อความบนปุ่มคงเป็นภาษาอังกฤษตามที่ Geno แสดงจริง
- **การ์ดข้อมูล** ในบางจังหวะ เป็น JSON ของ request ที่ Geno ส่งให้ model คำตอบที่ได้กลับมา หรือ event ที่ Geno บันทึก
  หัวการ์ดบอกที่มา "ข้อมูลจากการรันจริง" คือคัดจากการรัน Geno กับ model จริง
  "ข้อมูลจาก engine จริงกับ model จำลอง" คือ engine จริงแต่คำตอบของ model เขียนไว้ล่วงหน้า
  ส่วนที่ไฮไลต์คือสิ่งที่เรื่องเล่าพูดถึง ส่วนที่พับไว้คลิกเปิดได้
- **ดูขั้นในโค้ด** ขั้นละเอียดของโค้ดในจังหวะนั้น แต่ละขั้นมีลิงก์ `path:line` ที่เปิดบรรทัดนั้นใน VS Code

เลขบรรทัดคำนวณตอนสร้างเว็บจากชื่อฟังก์ชันหรือข้อความในโค้ด จึงตรงกับโค้ดเสมอ

## การควบคุม

| ทำอะไร | วิธี |
| --- | --- |
| จังหวะถัดไป / ก่อนหน้า | ปุ่ม **ถัดไป** / **ย้อนกลับ** หรือแป้น → / ← |
| กระโดดไปจังหวะใดก็ได้ | คลิกจังหวะในแผนภาพ |
| เลือกทางที่ทางแยก | ปุ่มในการ์ดอ่าน หรือกล่องทางแยกในแผนภาพ |
| เริ่มใหม่หรือลองทางอื่น | **เริ่มใหม่** / **ลองทางอื่น** ที่จังหวะสุดท้าย |

ที่อยู่ในแถบของเบราว์เซอร์ (`#at=...`) ตามคุณไปทุกจังหวะและทุกทางแยก คัดลอกไปแบ่งปันได้
ถ้าปิด JavaScript หรือพิมพ์หน้าออกมา ทัวร์จะเป็นรายการทุกจังหวะ โดยแต่ละทางแยกแสดงทุกทางซ้อนอยู่ในที่ของมัน

## ทำไมบางหน้ามีทัวร์ บางหน้ามีแผนภาพ

เรื่องที่มีขั้นให้เดินตาม เช่น prompt หนึ่งข้อเดินทางไปถึง model เป็นทัวร์แบบโต้ตอบได้
เรื่องที่ไม่มีลำดับ เช่น เครื่องสถานะ ความสัมพันธ์ของชนิดข้อมูล หรือโครงสร้าง process เป็นแผนภาพนิ่งในหน้า
