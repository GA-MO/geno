## Geno คืออะไร

Geno เป็นเอเจนต์เขียนโค้ดใน VS Code คุณพิมพ์งานเป็นภาษาคน แล้ว Geno ทำงานนั้นในโฟลเดอร์ของคุณ
อ่านไฟล์ แก้ไฟล์ และรันคำสั่ง จนเสร็จแล้วรายงานกลับ

AI model ที่อยู่เบื้องหลังเป็น HTTP API ที่ไม่มีความจำ และรันอะไรบนเครื่องคุณเองไม่ได้
มันทำได้แค่อ่าน request แล้วเขียนคำตอบ ซึ่งอาจเป็นข้อความถึงคุณ หรือคำขอใช้ **tool**
(ความสามารถที่ Geno เปิดให้ เช่น อ่านไฟล์หรือรันคำสั่ง)
งานที่เหลือทั้งหมดเป็นของ Geno: เก็บบทสนทนา ตรวจว่าคำขอนั้นทำได้ไหม รัน tool แล้วส่งผลกลับไปให้ model

prompt หนึ่งข้อของคุณกลายเป็นหนึ่ง **turn** คือช่วงตั้งแต่คุณกดส่งจนคำตอบจบ
ใน turn หนึ่ง Geno อาจเรียก model หลายครั้ง วนอย่างนี้จน model บอกว่าเสร็จ หรือมีอะไรมาหยุด
เหมือน REST request หนึ่งครั้งที่ server เรียก service อื่นหลายรอบก่อนตอบคุณ

ส่วนที่วนนี้ไม่ได้รันใน VS Code แต่รันใน **Geno engine** ซึ่งเป็นโปรแกรมแยก (`gcode serve`)
แผงแชตส่งข้อความให้ส่วนของ Geno ที่รันใน VS Code และส่วนนั้นคุยกับ engine ผ่าน Unix socket
(ช่องสื่อสารระหว่างสองโปรแกรมในเครื่องเดียว ที่อยู่เป็น path ของไฟล์แทน port)
[ส่วนประกอบของ Geno](/foundations/parts-of-geno/) เดินผ่านทุกส่วนทีละขั้น

ทุกทัวร์เล่าด้วยผู้เล่นห้าฝ่ายเดียวกัน: **คุณ** **Geno panel** **Geno engine** **AI model** และ **เครื่องของคุณ**
แต่ละจังหวะมีรายละเอียดของโค้ดซ่อนอยู่ใต้ "ดูขั้นในโค้ด" พร้อมลิงก์ไปยังบรรทัดที่ทำงานจริง
