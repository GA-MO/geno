## Geno คืออะไร

Geno เป็นเอเจนต์เขียนโค้ดใน VS Code ที่มีลูปของตัวเอง
ลูปนั้นไม่ได้รันใน extension host แต่รันใน **engine** แยกต่างหาก (`gcode serve --socket`)
แผงแชตคุยกับ extension host และ extension host คุยกับ engine ผ่าน Unix socket

prompt หนึ่งข้อของคุณกลายเป็นหนึ่ง turn ระหว่างนั้น engine ผลัดกันทำงานกับ model
model ตอบหรือขอเรียก tool Geno ตรวจสิทธิ์ รัน tool แล้วส่งผลกลับไปให้ model
วนอย่างนี้จน model จบ turn หรือมีอะไรมาหยุด

ทุกทัวร์เล่าด้วยผู้เล่นห้าฝ่ายเดียวกัน: **You** **Geno panel** **Geno engine** **AI model** และ **Your machine**
แต่ละจังหวะมีรายละเอียดของโค้ดซ่อนอยู่ใต้ "Show internals" พร้อมลิงก์ไปยังบรรทัดที่ทำงานจริง
