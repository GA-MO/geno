**Geno:** **tiny-shop** — โปรเจกต์สาธิตขนาดเล็กมาก เป็น helper เรื่องราคา/ผู้ใช้ ไม่มีเซิร์ฟเวอร์จริง รันเทสต์ด้วย `node --test`

โครงสร้าง:
- `src/money.ts` — `formatPrice(cents)`
- `src/slug.ts` — `slugify(title)`
- `src/user.js` — Map ผู้ใช้ใน-memory (มีแค่ Ada, id=1)
- `src/routes.js` / `src/profile.js` — ฝั่งที่เรียก `getUser`
- `build/`, `dist/` — ไฟล์ artifact เก่า ว่างเปล่าแทบไม่มีเนื้อหา
- `.vscode/mcp.json` — ชี้ไป fake MCP server (`wsfake`) ที่อยู่นอก workspace นี้ ซึ่งยังไม่ได้ approve จึงใช้ไม่ได้

เคสน่าสนใจที่เจอตอนลองรัน (ยังไม่ได้แก้โค้ด):

1. **เทสต์พังอยู่แล้ว** — `formatPrice` ใช้ `cents / 100` เฉยๆ ไม่มี `toFixed(2)` ดังนั้น `formatPrice(1250)` ได้ `"$12.5"` แต่ `test/money.test.ts:4` คาดหวัง `"$12.50"` → `npm test` fail 1 เคสนี้
2. **ไม่สอดคล้องกันระหว่าง routes กับ profile** — `routes.js:3` แปลง `Number(id)` ก่อนส่งเข้า `getUser` ส่วน `profile.js:3` ส่ง id ดิบๆ เพราะ Map ใช้ key เป็น number ทำให้ `userRoute("1")` คืน Ada แต่ `title("1")` คืน `"Profile of nobody"` (เงียบๆ ไม่ error)
3. `src/money.ts` ยังเพี้ยนกับราคาที่เป็น cents คี่มากๆ ได้ เช่น `formatPrice(1)` → `"$0.01"` ถูกโดยบังเอิญ แต่ `formatPrice(12345)` → `"$123.45"` และ `formatPrice(10000000000000001)` จะเสีย precision เพราะใช้ number ล้วน

ถ้าจะแก้ จุดที่คุ้มสุดคือ `formatPrice` (ใส่ `.toFixed(2)`) และให้ `profile.js` แปลง id แบบเดียวกับ `routes.js` — บอกได้เลยถ้าต้องการ
