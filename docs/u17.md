# U17: a quiet chat

A finished turn now shows the user's message, one summary line, the final answer, the files it changed, and anything that needs the user. Its other steps fold behind the summary line. `gcode.chat.detail` switches between `compact`, the default, and `full`, the view from before U17, without a reload.

## What a compact turn shows

- The summary line, such as "Read 4 files · searched 3 times · edited 1 file · ran 2 commands · 1 failed". Clicking it opens the full trail, with the model, tokens and cost under it. Clicking it again folds the turn. The line stays where the user clicked it, so the answer below it moves and the text the user reads does not jump.
- The final answer: the text after the turn's last call. A turn that ended on a call has no final answer, and shows its summary line and changed files only.
- The changed files as one row of chips with `+n −m`. Each chip opens its file at the first hunk. Keep all and Undo all show while any hunk waits for review.
- Steps that need the user: any step whose rail node waits on the user, such as an approval card, and an error, which only ends a turn.
- The model, tokens and cost as the tooltip of "worked for".

A running turn shows its current step and the three before it, and only its latest narration. Its earlier steps fold behind "+N earlier steps". Those recent steps leave out an MCP call's arguments and the Auto-approved badge. An Auto-denied badge still shows.

Each turn's open or folded state lives in the webview, next to the steps the user opened. Sessions loaded from the history render compact too.

## Where the rules live

`packages/extension/src/chat/fold.ts` is pure. `turnView` names the turn's view model: its trail, summary, final answer, changed files and attention steps. `summaryOf` counts calls through one table keyed by tool kind, so a new kind adds a row. `shownSteps` picks the steps the rail draws for a detail and a fold state. The unit tests are in `packages/extension/test/fold.test.ts`.
