# U8: images and file attachments

The user can send Geno images and text files, and Geno shows images in the chat. The brief is `docs/u8-brief.md`.

## Sending

- Paste an image with Cmd+V, drop files on the composer from Finder or the explorer, or pick them with "Attach file…", the first row of the `+` menu. Each attachment is a chip with a thumbnail or file icon, its name, its size and a remove button.
- The webview reads each file and decides what it is from its bytes. An image whose long side is past 1568 px, or that is over 1 MB, is drawn again at 1568 px. A JPEG stays JPEG. Anything else becomes PNG, unless it is a large photo saved as PNG and JPEG comes to less than half the size.
- A message holds 8 images and 5 MB of attachments. Past either limit, and for a PDF or another binary file, the chip says "Not attached" and a line under the chips says why.
- The extension sends images as ACP `image` blocks and files as embedded text `resource` blocks, each marked with `_meta["gcode/attachment"] = { name }`. The engine puts images first in the user message, then the prompt, then files as `<context_item kind="file">`, the same as an `@file`.

## Storage and replay

- The engine writes each attachment once to `$GCODE_HOME/sessions/<id>/attachments/<sha256>.<ext>`. It writes a temporary file and renames it, so a crash cannot leave a torn file, and storing the same bytes again changes nothing.
- The `user` event records `attachments`: kind, hash, media type, name, size, the source path when there was one, and the pixel size of an image. The log never holds the bytes.
- Before each model call the engine loads the bytes every event references, so a resumed session sends the same request bytes. If an attachment is gone, the model gets a one-line note instead.

## Showing

- `read` returns a png, jpg, gif or webp file up to 5 MB as an image in its `tool_result`, stored by hash the same way. The step shows a thumbnail of the workspace file.
- A markdown image in an answer that names a workspace file renders inline through the webview's address for that folder. A remote image, or one outside the workspace, is shown as a link with a note and never loads. The CSP's `img-src` allows only the webview's own roots and the `data:` thumbnails the panel draws.
- Clicking a thumbnail opens the file in an editor tab. A pasted image opens from the session's attachments folder.

## Media

All in `docs/media/u8/`, in Dark Modern (`-dark`), Light Modern (`-light`) and Dark High Contrast (`-high-contrast`).

- `composer-*.png`: an image chip and a file chip in the composer.
- `sent-*.png`: the sent image and file above the prompt.
- `read-*.png`: a `read` thumbnail on its step, the same image inline in the answer, and a remote image left as a link.
