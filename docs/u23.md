# U23: subagents in the panel

U22 gave the engine subagents. U23 shows them in the chat panel. Each child sits under the `agent` call that started it, opens into its own transcript, and can be cancelled while it runs. A small helper dino stands in each running child's row, and the composer's agents pill counts the running children. The brief is the U23 section of `research/competitors-2026-10.md` section 5.

## ACP

The extension advertises `subagents: {}` in its client capabilities. ACP SDK 1.7.0 has the field (`ClientCapabilities.subagents`, marked unstable), so the panel uses the native path and not `_gcode/subagent`. The native path is the only one that streams the child's own work under its session id. With `_gcode/subagent` the panel would get the start and the end, but no transcript to open.

- `subagent_update` on the parent session carries the engine's `SubagentNotice` under `_meta["gcode/subagent"]`. `subagent-host.ts` parses it with zod. The status `running` becomes a `child-start` action, and any other status becomes `child-end` with the end, turns and cost.
- An update whose session id is a known child becomes a `child` action that wraps the text, notice, tool or diff action the parent would get. Nothing from a child reaches the parent's blocks. A file the child writes gets its diff on the child's own step.
- Cancel sends `session/cancel` with the child's id. The engine stops that child alone, and the parent goes on with the partial report.
- A child's permission questions come on the parent's call, as U22 sends them, so they show in the parent's rail as before.

**Engine hook.** `SubagentNotice` gains `toolUseId`, the parent's `agent` call. Without it the panel could not tell which of two parallel calls a child belongs to. `subagent-acp.ts` fills it in, and the U22 e2e test checks it. Nothing else in the engine changed.

## Data shape

- `Child` in `packages/extension/src/chat/messages.ts`: `id` (the child's session id), `toolId`, `role`, `model`, `status` (core's `ChildStatus`), `startedAt`, `endedAt`, `turns`, `costUsd` (known once it ends), and `turn`. `turn` is the child's own transcript as one `Turn` whose prompt is the task.
- `Turn.children` maps child session id to `Child`, in the order the children started.
- Actions: `child-start`, `child` (`{ id, action }`, where `action` is a text, notice, tool or diff action), and `child-end`. The reducer in `transcript.ts` runs a child's action through the same reducer as any turn, so the child's rail follows the same rules as the chat's. A child ends once, and a later end changes nothing. A parent turn that ends cancels a child still marked running.
- Navigation in `webview.ts`: `Focus` is `{ kind: 'parent' }` or `{ kind: 'child', id, scroll }`. `scroll` is where the chat was, so Back returns to the same place.

## In the panel

- **Rail.** `railOf` turns an `agent` call into an `agent` step with its children. The step is the usual call row, "Delegating to explore: <task>", with a list of child rows under it. Each row shows a status (the helper dino while it runs), the role, the model, the time, the cost once known, and a chevron. A running row has Cancel. The step stays live while any of its children runs, even after the call itself reported back. The call's own spinner hides once it has children, since the rows say they run.
- **Side view.** Clicking a row opens the child's transcript in place of the chat and the composer. The head has Back, Cancel while the child runs, the role and model, its status, time, cost and model calls, and the task. The rail below is the child's own turn in full detail. Back, or Escape, returns to the chat at the same scroll position, with the keyboard on the row that was opened. Escape in the side view never stops the turn.
- **Clocks.** A running child's clock carries its start in `data-since`, and `tickClocks` moves it each second without rebuilding the row. Rebuilding it would take the keyboard off Back or a row.
- **Helper dinos.** `helper-dino.ts` keeps a 1× Noodle per running child in that child's row. Each helper is steered by U18b's `steer` over the child's own turn, so a child that reads shows the reading pose. Helpers tick on their own motion gate, and stand still under reduced motion and high contrast. A child that ends takes its helper with it.
- **Agents pill.** The pill comes back in the composer's running row, with real data. It is in the DOM only while at least one child of the turn runs, so the idle row is as U36 left it. It reads "1 agent" or "N agents". With one running child it opens that child. With several it opens a short menu of them, with the mode menu's keys (arrows, Enter, Escape back to the pill).
- **Narrow panel.** The running row now holds the clock, the cost, the pill, the ring, the model and Stop. A container query on the bottom row gives things up in order while a turn runs. Below 460px it drops the effort and the cost, which the turn footer repeats. Below 360px it drops the model name and the clock's icon, shows the pill as its icon and count, and tightens the gaps. The integration test measures the row at a 300px panel and fails if any control sits outside it.

## Check

- `packages/extension/test/subagents.test.ts` covers nesting under the right call, the child's own turn, a live step after the call returned, a single end, cancel on the parent's end, an idempotent start, the pill's count and children, and parsing `subagent_update`.
- `packages/extension/test/subagents.integration.test.ts` runs the real engine against a fake model in VS Code. It routes each request by a marker in its conversation. It covers two parallel explorers nested under their calls with helper dinos and Cancel, the pill and its menu, the bottom row at 300px, opening a child from the menu and from its row, Back and Escape with the keyboard returned, the pill counting down and opening the one remaining child, both children done with cost, and Cancel on a hung child. After the cancel, the parent finishes with the report marked `cancelled` and partial. The side bar is resized by dragging its sash over CDP, so the 300px width is exact.
- `pnpm typecheck && pnpm lint:deps && pnpm vitest run --project unit && pnpm build`.

## Deferred

- A session loaded from the history shows its `agent` calls without children. The replay does not carry the children's logs.
- A running child's cost shows once it ends. The child's stream sends no `usage_update`, and the brief allows no engine change for that.
