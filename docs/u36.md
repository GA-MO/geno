# U36: composer v2

The composer follows the mockup the user approved on 2026-10-06. A tray of chips sits above the text. Below the text, `+`, `/` and the mode pill sit on the left. The context ring, the model with its effort, and Send or Stop sit on the right.

## What the composer shows

- **Tray.** One row that scrolls sideways. It hides while empty.
  - "Browser · localhost:3000" with a green globe, while the session's built-in browser runs. The host is the one the browser last opened. Its × turns the browser off, as the MCP pane's switch does.
  - Image chips with a thumbnail and the size the model sees, such as "Screenshot 1.png 1034×1239".
  - File chips with an icon, the name and the size.
  - `@` mentions, and a follow-up queued while a turn runs.
- **Bottom left.** `+` types an `@` and opens the attach and `@` menu. `/` puts a `/` in front of the draft, which opens the command picker. The mode pill is neutral in Ask and amber in Auto.
- **Bottom right.**
  - The context ring fills with the tokens in context over the model's window. Its tooltip gives the numbers. From 80% it turns amber and a Compact pill sits beside it, which sends `/compact` (U47, `docs/u47-panel.md`). For a model with no known window it shows the tokens only, with a dashed track.
  - The model name, with the effort in muted text. One menu picks either. The models are the ready providers' default and priced models, then "Models and Keys…". The efforts are the ones the engine offers through the ACP `effort` config option. On Model Studio a muted line says that an effort change mid-chat rewrites the prompt cache once (U21).
  - Send: a white circle with a dark arrow in dark glass, near-black in light glass.
- **While a turn runs.** The placeholder is "Queue a follow-up…", and Enter queues the draft. The queued follow-up goes when the turn finishes, or comes back to the composer if the turn stops or fails. The bottom row shows the elapsed time, and the turn's cost in baht with USD in the tooltip. While subagents run, a green agents pill counts them and opens them (U23, `docs/u23.md`). Stop is a square on a dark circle.

`gcode.chat.bahtPerUsd` sets the rate, 33 by default. `/model` opens Models and Keys.

Enter sends and Shift+Enter makes a newline. Enter never sends while an IME composes: the composer checks the key's `isComposing` flag, keyCode 229, and its own composition events.

## Where it lives

- `packages/extension/src/chat/composer-model.ts` is pure. `composerView` maps the transcript, the host's `ComposerFacts`, the MCP listing, the queued follow-up and the time to a `ComposerView`, one field per slot.
- `composer-host.ts` keeps the facts in the extension host. It reads the effort option from `session/new`, `session/resume`, `session/load` and `config_option_update`, sets it with `session/set_config_option`, and reads `usage_update`.
- `composer-view.ts` draws a `ComposerView`. `composer.css` styles it.
- The engine sends ACP `usage_update` after each model call, and once on load and resume. `size` is the window from `CONTEXT_WINDOWS` in core, or 0 when unknown. `_meta["gcode/usage"]` carries the turn's cost so far.

## Media

All in `docs/media/u36/`, in Dark Modern (`-dark`), Light Modern (`-light`) and Dark High Contrast (`-high-contrast`, native). Each has a window capture and a `-panel` capture of the panel at 2x.

- `idle-*`: a new chat.
- `menu-*`: the model and effort menu.
- `attachments-*`: the browser, an image and a file in the tray.
- `running-*`: a running turn with a queued follow-up.

`GCODE_SCREENSHOTS=docs/media/u36 pnpm vitest run --project vscode packages/extension/test/composer.integration.test.ts` retakes them.
