# U40: an Agents section in the settings page

The settings page now has an Agents section, between Roles and Providers. For Cursor it installs the CLI, signs in, updates and signs out, so the user never has to type `agent login` or `agent update` in a terminal. It is the account half of using Cursor's agent from Geno. The ACP backend that drives `agent acp` is U33.

## What the user sees

The Cursor card shows one of these states:

| State | The card shows |
| --- | --- |
| Checking | "Looking for the CLI…" |
| Not installed | Install Cursor CLI, Check again and a link to Cursor's install guide |
| Installing | "Installing in the terminal…" and Check again |
| Signed out | The CLI's path, its version with Update, "Signed out" with Sign in |
| Signed in | The same, with the account `agent about` names and Sign out |
| Signing in | "Waiting for the browser…", a link to the sign-in page, the CLI's output and Cancel |
| Updating, Signing out | A spinner, the output and Cancel |
| Error | Why the status check failed, its output, Update and Check again |

After a command ends, the card says how it ended ("Sign-in cancelled.", "Update finished.", "Sign-in failed (exit code 1).") with the command's output, until the next command.

Install Cursor CLI and Sign out each ask first, inside the card, as discarding a lane does. The install question names the exact command, `curl https://cursor.com/install -fsS | bash`, says it downloads from cursor.com and puts the CLI in `~/.local/bin`. On Install, Geno opens a VS Code terminal named "Install Cursor CLI", shows it and types the command there. Geno downloads and runs nothing itself. Closing that terminal checks again; so does Check again.

## The CLI it is built on

Recorded from Cursor CLI `2026.01.23-916f423` on this Mac, signed out:

- `agent --help` lists `login` ("Set NO_OPEN_BROWSER to disable browser opening"), `logout`, `status|whoami`, `about` and `update|upgrade`. None of the four has options of its own (`agent login --help` and the others).
- `agent status` prints " Starting login process..." and then, after terminal erase codes, " Not logged in". A third party's issue quotes the signed-in output as "Logged in as …".
- `agent about` prints "Loading..." over a spinner, then a table: `CLI Version`, `Model`, `OS`, `Terminal`, `Shell` and `User Email`, which reads "Not logged in" when signed out.
- `agent --version` prints `2026.01.23-916f423`.

Geno reads `agent about`. One call gives the version and the account, as labelled rows that do not depend on wording. `agent status` says "Starting login process" even to report that nobody is signed in, and gives no version. Without a `User Email` row the output is unknown and the card shows the error state. This machine has no signed-in recording: the signed-in unit test fills the recorded table's row with `user@example.com`.

Cursor's install page gives the command above and says to add `~/.local/bin` to PATH. The installed `agent` here is a link in `~/.local/bin` to `~/.local/share/cursor-agent/versions/<version>/cursor-agent`.

## Data shape

`packages/extension/src/chat/agents-model.ts`, pure and shared with the page:

- `EXTERNAL_AGENTS`: one row per agent, with its id, label, binary names (`agent`, `cursor-agent`), the folders under home its installer uses (`.local/bin`), its status command and parser, its login, logout and update commands, and its install command, source, location and docs link. Claude Code can join as a second row.
- `AgentState`: the union in the table above.
- `agentReducer(state, event)`: the transitions, for `check`, `checked`, `install`, `start`, `output` and `exit`. One command runs at a time, and a check cannot interrupt it.
- `redact`, `shownOutput`, `firstLink`, `linkLabel`, `parseCursorAbout`.

`agents-host.ts` holds the effects. It finds the CLI with `findExecutable`, which now also looks in extra folders after Homebrew's and PATH, so a VS Code started from the Dock finds `~/.local/bin/agent`. It runs the status check with `NO_OPEN_BROWSER=1` and a 30 second timeout, and runs login, logout and update with `spawn` and `shell: false`. `settings-host.ts` owns one `AgentsHost` and passes its messages through.

## Credentials

Geno runs only the CLI's own commands and never reads Cursor's files, tokens or config. What a command prints goes through `shownOutput` before it reaches the page: terminal codes are stripped, a URL's query is cut to `?…`, and JWTs, `token: …`-style pairs, `sk-`-style keys and long letter-and-digit runs become `[redacted]`. The output channel gets only the command names and exit codes. The sign-in address stays in the extension host. The page gets only its host name, and the link asks the host to open the address with `vscode.env.openExternal`. Only an `https://` address is opened.

## Checks

- `packages/extension/test/agents.test.ts`: the recorded `about` and `status` output, terminal codes, redaction, the sign-in link, and every state transition.
- `packages/extension/test/agents.integration.test.ts` launches VS Code with PATH set to an empty folder and `/usr/bin:/bin`, and HOME set to an empty folder, so the user's own CLI is never found. The fake `agent` is a shell script from `suite/agents-fixture.ts` that prints the recorded `about` table, and logs every call. Its `login` prints a sign-in address with a challenge and a token line, then waits for a file. The default terminal profile is `/bin/sh -c 'cat > …'`, so the install command is recorded and never run. The suite drives missing, the install confirm, the terminal and its command, the re-check when the terminal closes, the fake appearing on PATH, Check again, signed out, sign in with the link (the challenge and token absent from the page), Cancel, sign in to signed in, Update, and Sign out with its confirm (Cancel first). It checks the path it found is the fake before the first click that runs it, and that the CLI saw exactly `about, login, about, login, about, update, about, logout, about`, with `NO_OPEN_BROWSER=1` on every status check only.
- The resize helper of the lanes and subagents tests moved to `test/media.ts`, so all three share it.
- Not tested: the link's click, which would open a real browser on the test machine.
